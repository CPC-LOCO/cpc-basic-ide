CPC BASIC IDE - version 0.3.0 (version de test)
================================================

Un editeur colore et un compilateur pour un BASIC evolue, derive du
Locomotive BASIC, qui cree des programmes en langage machine pour
Amstrad CPC (464, 664 et 6128).

C'est une version de test, publiee pour recueillir des retours. Presque
tout le Locomotive BASIC est maintenant compile : textes, nombres a virgule,
tableaux, graphismes, sons, clavier, fichiers, interruptions, erreurs.
La liste complete, commande par commande, est dans COMPATIBILITE.md.


1. LANCER L'EDITEUR
-------------------
Decompressez tout le dossier, puis double-cliquez sur CpcIde.exe.
Aucune installation n'est necessaire, et il n'est pas utile d'installer .NET.


2. L'EDITEUR
------------
Barre de menus (touche Alt, puis la lettre soulignee) :
  Fichier   Ouvrir (Ctrl+O), Enregistrer (Ctrl+S), Quitter
  Edition   Annuler (Ctrl+Z), Retablir (Ctrl+Y), Couper, Copier, Coller,
            Tout selectionner
  Compiler  Compiler le programme (F5), Verifier sans enregistrer
            (Maj+F5), Liste des variables (F4)
  Options   reglages F8, F9, F11, lignes longues, contraste eleve (Ctrl+H),
            taille du texte (Ctrl et +, Ctrl et -, Ctrl et 0)
  Aide      Raccourcis clavier (F1), A propos

Panneau des messages, en bas : les erreurs ont un X rouge, une compilation
reussie un V vert. F6 passe de l'editeur aux messages ; Entree ou un clic
sur une erreur amene le curseur sur la ligne. La barre grise au-dessus des
messages se tire a la souris pour agrandir le panneau.

Une ligne trop longue continue sur la ligne suivante de l'ecran, comme sur
le CPC (menu Options pour revenir a une seule ligne).

Un probleme imprevu ne ferme pas l'editeur : un message le signale, et le
detail est note dans %APPDATA%\CpcBasicIde\erreurs.txt (envoyez-le-nous).


3. LES COMMANDES DU CPC DANS L'EDITEUR
--------------------------------------
Tapez la commande seule sur une ligne, SANS numero, puis Entree :
  NEW            efface le programme (demande d'abord s'il faut l'enregistrer)
  AUTO           numerote les lignes : AUTO 100,5 ; ESC pour arreter
  EDIT 20        met le curseur sur la ligne 20
  RENUM          renumerote : RENUM 100,,5 ; les GOTO, GOSUB, THEN... suivent
  DELETE 10-50   efface des lignes (toujours une question avant)
  LIST           range les lignes par numero et les ecrit comme le CPC
                 (mots en majuscules) ; LIST 100-200 amene aussi le curseur
  100            un numero seul efface la ligne 100 (avec une question)
RUN, LOAD, SAVE, CAT, CLEAR, MEMORY, CONT, MERGE, CHAIN et les commandes
AMSDOS (|DIR, |DISC...) affichent ce qu'elles deviennent ici.
Ctrl+Z annule RENUM, DELETE et LIST.


4. COMPILER UN PROGRAMME
------------------------
- Ouvrez un programme (exemples : dossier examples) ou ecrivez le votre.
- Appuyez sur F5. Le programme est enregistre, puis un fichier .dsk est
  cree a cote.
- Dans un emulateur (WinAPE, Caprice32, SugarBox...), inserez le .dsk dans
  le lecteur A, puis tapez : RUN"NOM"   (NOM = le nom du fichier .bas)
- Avant de recompiler le meme programme, fermez l'emulateur : il garde le
  fichier .dsk ouvert et l'editeur ne peut plus l'ecrire.

Le nom du fichier .bas donne le nom sur la disquette : 8 caracteres au plus.
Un programme compile marche sur tous les CPC : il reconnait la machine au
demarrage. Si un programme lance un autre programme (RUN "SUITE"), F5
compile aussi SUITE.BAS et le met sur la meme disquette.

Reglages (menu Options) :
  F7   version du CPC : francaise (AZERTY, lettres accentuees, par defaut)
       ou anglaise (QWERTY) ; les textes montrent ce que le CPC affichera
  F8   variables sans signe (A, X...) entieres ou a virgule, comme le CPC
  F9   touche ESC comme le CPC (pause, puis arret) ou ignoree
  F11  met aussi le texte du programme sur la disquette (NOM.TXT), pour le
       comparer avec le vrai BASIC : LOAD"NOM.TXT" puis RUN


5. DIFFERENCES AVEC LE LOCOMOTIVE BASIC A CONNAITRE
---------------------------------------------------
  - Sans F8, A est un entier (et non un reel), et A et A% sont deux
    variables differentes. Avec F8, A est a virgule comme sur le CPC.
  - Sans F8, la division / est entiere (7/2 donne 3) ; avec F8, elle donne
    un nombre a virgule, comme le CPC.
  - CHAIN et MERGE sont refuses : utilisez RUN "nom" (et un fichier pour
    garder des valeurs).
  - Les lettres accentuees s'affichent sous la forme "?".
  - Un programme compile ne revient pas au BASIC : a la fin, il attend
    une touche, puis la machine redemarre.

Ajouts du projet : BYTE, DO ... LOOP, REPEAT ... UNTIL, EXIT, CONTINUE,
IF ... END IF sur plusieurs lignes, BOX, PAINT, CLAMP, RANDOM, HIBYTE,
LOBYTE.

Pas encore disponible : sortie cassette, cartouche GX4000, sprites.


6. ANTIVIRUS ET WINDOWS
-----------------------
Le programme n'est pas signe numeriquement. Windows (SmartScreen) ou votre
antivirus peut le signaler, ou bloquer son demarrage : c'est une fausse
alerte frequente pour les programmes libres non signes.
- La somme de controle (SHA256) de l'archive est indiquee dans la description
  de la version sur GitHub : vous pouvez verifier que le fichier est intact.
- Le code source complet est public : https://github.com/CPC-LOCO/cpc-basic-ide
- Si votre antivirus bloque le programme, ajoutez le dossier aux exclusions.
